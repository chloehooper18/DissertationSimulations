# Dissertation Simulations

## 01 - Simulations worksheet
### Simulating time series, power spectra and spectral models
- A series of notebooks detailing code for simulating time series, power spectra and spectral models
- Simulations focus around white, pink and brown noise

## 02 - Simulations 1ppt
### Simulating EEG electrodes for a single participant 
- Notebooks detailing code for simulating both single and multiple electrodes for a single participant
- Includes both 1D arrays and 2D clusters of electrodes
- Spectral Models are plotted for the simulations

## 03 - Avg Time Series exps
### Averaging Time Series across different manipulations
- Notebooks detailing code for averaging together Time Series signals
- Contains multiple experiments that vary by different manipulations

## 04 - Avg PSD exps
### Averaging PSDs across different manipulations
- Notebooks detailing code for averaging together PSD signals
- Contains multiple experiments that vary by different manipulations

## 05 - Avg SpecMod exponent exps
### Averaging SpecMod exponent across different manipulations
- Notebooks detailing code for averaging together SpecMod exponent signals
- Contains multiple experiments that vary by different manipulations

## 06 - Meta parameters
### Saving and plotting sweeps of different electrode methods and averaging methods
- Notebooks detailing code for running sweeps of different electrode with multiple averaging methods
- Contains code for saving sweep outputs as JSON files, loading the files and fitting results as a multi box plot figure

## 07 - Experiments
### Simulation frameworks
- Notebooks detailing the simulations frameworks ran
- Contains aperiodic and combined simulations as well as EEG data

## EEG data
### Open EEG data set - MIPDB
- Contains all EEG data files used in simulations

### Collection of scripts that contain functions that I have create for these simulations 
Includes:
- Set paramters

- Generating 1D and 2D electrode arrays
